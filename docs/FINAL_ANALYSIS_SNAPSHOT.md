# Final analysis snapshot

This package contains the final D129/D175 five-fold evaluation data used by the
manuscript, including the selected Fold 3 and Fold 4 D175 outputs.

The final server statistics report:

- D175 minus D129 binary foreground Dice: mean `-0.0009344700`; two-way
  case-fold bootstrap 95% CI `[-0.0029662918, 0.0009847422]`.
- D175 minus D129 identification rate: mean `0.0016656650`; two-way case-fold
  bootstrap 95% CI `[-0.0128574704, 0.0196532031]`.
- Bootstrap repetitions: `100000`; seed: `20260629`.

The paired ledger, statistics, calibration residual background, figures,
tables, manuscript values, repository manifest, and checksums all refer to this
single final analysis dataset.
